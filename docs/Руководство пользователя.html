1. Что делает приложение

ДМС-ассистент анализирует файл клиента (запрос на страхование) и сопоставляет его требования с нормативной базой программ добровольного медицинского страхования. Приложение автоматически подбирает наиболее подходящую программу и формирует таблицу-ответ: какие пункты запроса покрываются, какие покрываются частично, а какие отсутствуют в программе.

Поддерживаемые форматы файла клиента: .xlsx, .xls, .docx, .pdf.

2. Из чего состоит приложение

Приложение — это два независимых EXE-файла, которые работают в связке:

ФайлРоль
API-сервис.exe Фоновый сервис обработки. Открывается в виде консольного окна с логами. Слушает http://localhost:8001. Само по себе никакого окна с кнопками не показывает — это "мотор" приложения.
ВСК ДМС-ассистент.exe Графический интерфейс. Именно с ним работает пользователь: выбор файлов, кнопка «Подготовить», просмотр статуса и открытие результата.
Важно: GUI-приложение — это просто окно, которое посылает запросы в API-сервис. Если API-сервис.exe не запущен (или ещё не успел подняться), кнопки в GUI не будут работать — см. раздел «Возможные ошибки».

3. Запуск

Автоматический запуск (рекомендуется)

  1. Откройте папку с приложением.
  2. Дважды кликните run-all.bat.
  3. Откроются два окна: консоль API-сервис и окно ДМС-ассистент. Не закрывайте консольное окно API — приложение перестанет работать, если его закрыть.

run-all.bat сам копирует недостающие .env и config.json из примеров, если их нет, и ждёт несколько секунд после старта API перед запуском GUI, чтобы сервис успел подняться.

Ручной запуск

  1. Запустите API-сервис.exe и дождитесь в консоли строк вида Listening at: http://0.0.0.0:8001.
  2. Затем запустите ВСК ДМС-ассистент.exe.

4. Работа с приложением

  1. Нормативная база (необязательно) — файл с программами страхования, если нужно подставить свой вместо той, что зашита в поставку. Кнопка «Выбрать».
  2. Файл клиента (обязательно) — запрос клиента, который нужно обработать. Кнопка «Выбрать».
  3. «Оценить время работы» (необязательно) — показывает, сколько разделов найдено в файле и примерное время обработки. Появляется ползунок «% документа» — можно ограничить объём обрабатываемых данных, если нужно обработать только часть файла или ускорить прогон.
  4. «Подготовить» — запускает обработку. Кнопка становится недоступной, в карточке «Статус» отображается прогресс, прошедшее и ожидаемое время.
  5. «Открыть результат» — появляется после успешного завершения, открывает готовый файл с ответом в приложении по умолчанию (например, Excel).
Полоса прогресса и «прошедшее время» — это локальная оценка на основе прошлой оценки времени, а не точный прогресс от сервера. Реальная обработка может занять больше или меньше показанного времени.

5. Настройка

Рядом с ВСК ДМС-ассистент.exe лежит папка app/ с файлом config.json. Там можно поменять адрес API без пересборки приложения: 

{
  "api_base_url": "http://localhost:8001"
}

Настройки самого сервиса обработки (нормативная база, ключи для AI-провайдера и т.п.) хранятся в файле .env рядом с API-сервис.exe и применяются только при следующем запуске сервиса.

7. Возможные ошибки и их решение

Ошибка«Выберите файл клиента»

Нажата кнопка «Оценить время работы» или «Подготовить» без выбранного файла клиента.

Решение: нажмите «Выбрать» в блоке «Файл клиента» и укажите файл.

Ошибка«Файл "X" открыт в другой программе. Закройте его и попробуйте снова.»

Приложение не может скопировать выбранный файл в рабочую папку, потому что он открыт в Excel/Word/другом просмотрщике (файл заблокирован операционной системой).

Решение: закройте файл в другой программе и нажмите «Подготовить» ещё раз.

ОшибкаСообщение «Ошибка: ...» появляется сразу после нажатия кнопки, без прогресса

Обычно означает, что GUI не смог достучаться до API-сервиса — сеть/подключение недоступно.

Решение:

  • Убедитесь, что консольное окно API-сервис.exe открыто и не закрылось само.
  • Проверьте в консоли API, что там нет ошибки при старте (например, о неверном .env).
  • Если запускали вручную — подождите 5–10 секунд после старта API перед тем, как нажимать кнопки в GUI.
  • Проверьте api_base_url в app/config.json — порт должен совпадать с тем, что показывает консоль API (по умолчанию 8001).
Ошибка«Ошибка оценки: ...» / «Unsupported file format»

Формат выбранного файла не поддерживается, либо файл повреждён/не читается.

Решение: используйте один из поддерживаемых форматов — .xlsx, .xls, .docx, .pdf. Старый бинарный формат .doc (Word 97-2003) не читается — пересохраните файл в .docx.

Ошибка«Ошибка 500: ...» после длительной обработки

Ошибка на стороне сервиса обработки, обычно связана с обращением к AI-модели: неверный или просроченный ключ API, модель недоступна из текущей сети, или сервис модели вернул ошибку.

Решение:

  • Проверьте текст ошибки в консоли API-сервис.exe — там будет более подробное сообщение.
  • Если организация работает через прокси, убедитесь, что скопирован и заполнен proxy.env (из proxy.env.example) — без него обращение к внешнему API модели может не проходить через корпоративную сеть.
  • Проверьте актуальность ключа доступа к модели в .env рядом с API-сервис.exe.
ОсобенностьОбработка идёт очень долго / кажется, что «зависла»

Большие файлы с большим числом разделов обрабатываются по частям — время обработки растёт пропорционально объёму документа. Показанный процент и «прошедшее время» — это оценка на клиенте, а не подтверждение от сервера, поэтому расхождение с реальностью — норма.

Что делать: используйте кнопку «Оценить время работы» перед запуском, чтобы увидеть ожидаемое время, и при необходимости уменьшите ползунок «% документа», чтобы обработать файл частично быстрее (например, для проверки на малом фрагменте).

ОшибкаGUI-приложение не запускается / сразу закрывается

Частые причины: файл заблокирован антивирусом как незнакомый исполняемый файл (типично для приложений, собранных PyInstaller), либо Windows SmartScreen блокирует запуск неподписанного EXE.

Решение:

  • Проверьте карантин антивируса — добавьте API-сервис.exe и ВСК ДМС-ассистент.exe в исключения.
  • Если Windows показывает предупреждение SmartScreen — «Дополнительно» → «Выполнить в любом случае».
  • Проверьте app.log рядом с GUI-EXE — если он не создался, файл не запустился совсем; если создался, но приложение закрылось, там будет причина.
ОшибкаAPI-сервис не стартует / порт занят

Порт 8001 уже занят другим процессом — например, уже запущенным экземпляром API-сервис.exe, оставшимся от предыдущего запуска.

Решение: откройте Диспетчер задач, завершите все процессы API-сервис.exe, запустите заново.

ОсобенностьКнопка «Открыть результат» ничего не делает или открывает не то приложение

Кнопка открывает файл результата в приложении по умолчанию для его типа (обычно Excel для .xlsx). Если для этого формата не назначено приложение по умолчанию — ничего не произойдёт или откроется диалог выбора программы Windows.

Решение: назначьте приложение по умолчанию для .xlsx/.docx в настройках Windows, либо откройте файл вручную из папки uploads/.

ИнфоКуда обращаться, если проблема не решилась

Соберите вместе: скриншот ошибки в GUI, текст из консоли API-сервис.exe, файл app.log, и (если обработка дошла до сервиса) файлы *_llm_debug.md / *_llm_output.json из папки uploads/ для соответствующего запроса — это значительно ускорит диагностику.
